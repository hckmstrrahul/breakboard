# Raspberry Pi High Quality Camera — CS mount

This is an educational 3D reconstruction for breakboard, not manufacturing CAD. The model uses millimetres, +Y along the optical axis. The default and exploded views derive from the same geometry. The CS variant is shown with its supplied C-to-CS adapter and tripod bracket, without a lens, dust cap or detachable ribbon cable.

## Proof and rebuild

- `npm run build` builds the application and offline HTML.
- `npm run check` exercises registered builders, inventories, poses, picking and interfaces.
- `src/hqcamera.js` is the complete procedural source. It has no network runtime dependency.
- Verified geometry: finite vertices, 13 nonempty selectable groups, full 0–100% separation range and floor clearance. PCB and optical metadata live on `root.userData` for checks.
- Render proofs use the actual WebGL viewer at an 800 × 739 px viewport, in assembled, exploded and anatomy states. Larger README exports are generated by the app’s Save image control.

Source PDFs and photographs are reference material only and are not redistributed. Raspberry Pi and Sony names identify the represented hardware; this is an independent reconstruction.
